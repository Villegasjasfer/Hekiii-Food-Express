# Hekiii Food Express

A Flutter food-ordering app for browsing a restaurant menu, saving favorite
dishes, and building a cart.

## Features

- Search dishes and filter the menu by category
- Browse popular meals, prices, and customer ratings
- Save and revisit favorite dishes
- Choose a saved delivery address or add a new location
- Edit profile name, email, and phone number; view delivery address and order count
- Add multiple items, adjust quantities, and review the cart
- Place an order and view its items, total, and delivery address in Orders
- Responsive layout for phones, tablets, and web

## Run locally

Install the Flutter SDK, then run:

```sh
flutter pub get
flutter run
```

Run the widget tests with:

```sh
flutter test
```

Food photography loads from Unsplash; emoji placeholders are shown if an image
cannot be reached.
